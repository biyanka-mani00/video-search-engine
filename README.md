# Video Search Engine

A vibe-coded multimodal video search engine.

## Tech Stack
- **AI/ML:** CLIP (OpenAI), Whisper (OpenAI)
- **Vector DB:** Qdrant
- **Metadata DB:** PostgreSQL
- **API:** FastAPI
- **Background Tasks:** Celery + Redis
- **UI:** Streamlit
- **Tracking:** MLflow

## Getting Started
1. `docker-compose up -d`
2. `pip install -r requirements.txt` (local dev)
